# 书漫屿

书漫屿是一款集成小说源和漫画源的阅读聚合器


## 主要功能

- **特色**：整合多种小说源和漫画源，支持在线阅读。
- **书源切换**：支持选择和切换不同书源，满足多样化的阅读需求。
- **书架收藏**：收藏喜欢的小说和漫画，方便管理与继续阅读。
- **阅读记录**：保存阅读历史，方便查找和继续阅读。
- **本地缓存**：支持缓存阅读内容，方便离线阅读。

## 项目说明

书漫屿目前处于持续开发与完善阶段，后续将逐步优化阅读体验、扩展书源并增加更多实用功能。
